# ESP32 Smart Display

An ESP32-powered e-paper display that shows real-time Spotify "Now Playing" information along with environmental data such as temperature and humidity.

## Overview

This project is a Wi-Fi connected smart display built using an ESP32 microcontroller and a 4.2" e-paper screen. It pulls data from the Spotify Web API to display the currently playing song and album artwork, and includes local sensor data for ambient information.

## Features (Planned)

- Display current Spotify track and album art
- Wi-Fi connectivity using ESP32
- Temperature and humidity sensor integration
- Battery-powered operation with charging support
- Low-power deep sleep mode
- Clean e-paper UI optimized for readability

## Hardware (Planned)

- ESP32 microcontroller
- 4.2" e-paper display
- Temperature / humidity sensor
- LiPo battery with charging circuit
- USB-C power input

## Goals

The goal of this project is to explore embedded systems, IoT connectivity, and low-power design while building a functional and aesthetically pleasing desktop display.
